# SpeechCare — OpenRouter AI prototype

Speech-language therapy management app with Firebase authentication/data, patients, sessions, reports, and an in-app SpeechCare AI assistant.

AI provider: OpenRouter.

The assistant is specialized for speech-language therapy. A privacy shield removes direct patient identifiers before AI requests. Real patient identity remains available locally for therapist-facing reports/documents.

See `AI_SETUP.md` for setup.
